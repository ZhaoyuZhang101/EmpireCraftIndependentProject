# ORBIS TerrainPerf3.2 · Continuous World

**基于 `ORBIS_TerrainPerf3_1_WaterClimate_Full.zip` 的完整源码升级包。不是 Perf3.1 补丁，不回退 Perf3 或 Perf2，也不是重新另做的演示项目。**

本包包含 Assets、Packages、ProjectSettings、原有场景/资源、此次修改的运行时代码和 Shader、中文说明及测试入口。保留二维权威世界、4×4 Zone、20 档正海拔、文明与 v1 存档；星球仍是只读摄影投影。

> **验证边界：本次执行了源码/资源检查、从实际方法体转译的 C++ 数值回归，以及从实际片元代码移植的离线 GLSL 图形探针。没有运行 Unity Editor、原生 C#、Unity Shader/HLSL/D3D11、Play Mode、Windows 构建或实机 FPS。该 ZIP 是完整源码候选版，不是已经通过 Unity 实机验收的成品或 EXE。不能把离线测试 PASS 当成用户机器上的 IPC 错误已被证明消除。**

## 打开工程

完整解压到一个新目录，用 Unity Hub 添加包含 `Assets`、`Packages`、`ProjectSettings` 的 `ORBIS_TerrainPerf3_2` 文件夹。版本沿用 **Unity 6000.0.47f1 / Built-in Render Pipeline**。不要把本包覆盖进自己的 URP/HDRP 工程，不需要另外导入 HPWater 或 Unity-SWE 的 HDRP 工程。

主场景：`Assets/ORBIS/Scenes/Orbis2DWorld.unity`。先等待资源导入，检查 Console，然后运行：

`Tools → ORBIS → Perf3.2 → Validate continuous world on current GPU API`

Windows 上复核本次 D3D11 问题可用 `Validation/Perf3_2/run_d3d11.ps1`。脚本不带 `-nographics`；无图形设备的批处理不能证明 Shader 编译成功。通过后再进入 Play Mode；菜单测试不代替画面、功能和帧时间验收。

## 这次实际写入的改动

| 问题 | Perf3.2 实现 |
|---|---|
| 球体粉红、Surface IPC | 拆开地表与体积大气编译路径；保留原 Surface 路径和 GUID；主地表片元改为 9 个采样器声明，旧源码归档在 Reference；命名光照/深度 Pass；加入显式轻量回退和 HUD 警告。不是仅改名、清缓存或隐藏报错。 |
| 海岸、湖岸阶梯和方形粗边 | 周期欧氏距离场 → 受地块中心水陆符号约束的两次平滑 → 单调三次重建 → 屏幕导数抗锯齿；岸滩改为窄材料过渡。显示场平滑，不修改 Tile 的水陆归属。 |
| 陆地生硬拼色和高度格纹 | 自然颜色使用独立平滑混合；高度/水深使用有界三次插值；地形明暗采用连续较宽采样，减少量化高度的棋盘状阴影。诊断类别、文明和地块选择继续离散。 |
| 河道直角、宽度相似 | 基于原排水连接构建二次贝塞尔弯道，以 8 段距离近似着色；宽度由汇流代理决定，边界宽度共享，增加共同截面的连续约束。原排水方向和流域不被视觉曲线改写。 |
| 海底深浅缺少可读性 | 原有 HPWater 适配光学继续使用；加入根据真实缓存水深的对数深浅色和海床起伏示意，浅海、陆架、深海更易区分。不是声称能透视数千米海底。 |
| 波纹偏色、重复直线或岸边厚圈 | 零扰动法线编码改成精确中性值；流向波纹双相交叉淡化、远景频率衰减；局部 SWE 的水域掩码与新曲线岸线一致；岸边泡沫按连续距离生成。 |
| 等高线压满画面 | 与显示高度共用单调三次场；导数抗锯齿、平坦区衰减、每五条主线加深、过密自动增大等高距；默认关闭。 |
| 二维没有云和大气 | 新低/高云缓存、云影、薄雾、晨昏、微弱月光/天光、聚落夜灯；可选示意雨幕与稀疏闪电。二维云读取同一 WorldData 的月气候，不新建第二套天气模拟。 |
| 草地/森林差异不足 | 增加 14 类派生植被覆盖和独立图层；草粒、疏密不同的树冠细节。旧存档的 12 类 Biome 枚举不变。 |
| 顺带优化 | 地形版本变化才重建数据贴图；二维云缓存最高 5 Hz、暂停或不需要时休眠；水光学与植被关闭时跳过相应计算；保留近景单任务 64×64 SWE，不新增逐 Tile GameObject。 |

## 在界面里查看

“地形”页：平滑地表颜色、连续地形明暗、草粒/森林细节、14 类生态植被、等高线与等高距。“水文”页：水面着色、水深/海底高差示意、岸滩、河口悬沙、波纹强度、局部守恒扰动和定位入海口。“气候”页：低/高云、云影、大气/薄雾、二维云透明度与质量、昼夜/晨昏、太阳角度、自动转光、夜灯、示意雨幕和闪电。

自然与文明图层显示环境叠加；纯数据诊断图层不叠云，以免误读。二维云缓存默认 256×128，另有 128×64、512×256。为了让地图默认保持可读，昼夜与自动转光默认关闭；开启后自动转光周期为 120 秒，与“每秒推进多天”的文明时间分离，避免闪烁。

云、云影、大气和昼夜开关连接二维/摄影入口，但两种显示并非同一渲染器：二维是低成本合成，摄影保留原体积云/大气。二维透明度和缓存质量只影响二维缓存；雨幕/闪电明确是二维示意，不能当作完整三维天气特效。地表支持回退时会在 HUD/Console 明示，出现回退不算完整光学验收通过。

## 存档、地形和版本

v1 `.orbis` 编码没有增加字段，原 Biome 仍为 12 类；新的 14 类植被是可重建的派生缓存。加载旧档沿用 Perf3.1 的保留原 Biome/肥力策略；明确点击“手动重算排水、气候和地貌”才按当前分类重算，建议先另存备份。默认种子、预设与历史场景仍保留。此次没有修改全球排水核心、浅水数值求解核心、文明人口规则或实时板块开关。

根目录旧版本 README、Manifest、SHA、Preview 与历史报告为追溯资料，不代表本次实际画面或测试。当前版本以 `VERSION_TERRAIN_PERF3_2.txt`、`TERRAIN_PERF3_2_MANIFEST.json`、`Validation/Perf3_2/RELEASE_VALIDATION.json` 为准。

## 测试与范围

本次连续地表 C++ 转译回归为 677,030 条断言，包含 10,000 组随机插值、周期/极区边界、欧氏距离、河道共享边及植被分支。原排水 8 个变体、局部浅水 4 个变体各 120 秒、65 组柯本分类也重新执行。三个片元探针的 Gamma/Linear 共 6 个 GLSL 变体编译通过；10 次合成数据渲染运行于 Mesa llvmpipe，不是 Unity 或硬件帧率测试。具体误差和源码哈希均见报告。

`Validation/Perf3_2/Artifacts/ALGORITHM_*.png` 仅为算法夹具结果，不是项目运行截图；Legacy Preview 同样不证明本次视觉已验收。尚未完成真实水动力侵蚀、冲积三角洲地形、全球 SWE、SSR/屏幕空间折射、HDRP RenderGraph/MRT 移植、新的三维树木模型、科学标定的气候 GCM 或独立的真实降雨模拟。
