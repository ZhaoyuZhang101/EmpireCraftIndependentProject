ORBIS / VI

云有厚度，水有来路。

这是一份基于原版 ORBIS 改进的独立 HTML 沙盒。无需网络、第三方库或 API。文明、战争、海流、季节、板块与存档功能仍然保留。不是 WorldBox 官方游戏或科研气候模型。

持续演变的云与天气

云量沿球面风场输送，随湿度、低压、抬升和移动天气扰动凝结、蒸发。所有云形尺度都随时间变化，去除了固定地理遮罩；气候带仍有干湿差异。低层积云、对流云和高空薄云使用三维密度、自遮蔽、多次散射近似和深度感知放大。精细模式使用 80 步与完整像素分辨率。高纬仍有投影拉伸；地图模式按从高到低的顺序合成云层。

河谷与蜿蜒河道

先求洼地溢流面，再选择最陡的下降方向连接源头、支流、湖泊与海洋。缓坡有更明显的曲流，陡坡保留较直河谷；河水高度沿程不增加。河道附近局部细分地表，真实下切河床与岸坡，水面按河床裁切；不是浮在地表上的蓝色线。宽度由汇水面积决定，流量受雨雪、土壤和融水影响。此处尚不模拟泥沙搬运、河道迁移或完整水动力。

日照、蓄热与温室效应

季节平均温度使用简化单层大气辐射平衡，考虑太阳强度、雪冰反照率、水汽、云的短波反射和长波保温。实时地表温度叠加随当地日照积分的蓄热变化：白天升温、夜间散热，海水比干燥陆地变化慢，暖峰可晚于正午。黑夜不一定比所有白昼地区冷，海洋余热、纬度、海拔和湿度仍起作用。右侧显示吸收日照、长波通量和温室增温估计。生态使用慢速气候均温；不是可用于科研或预报的完整气候模型。

可恢复的干湿循环

蒸发、降雨和土壤储水统一按水量计算。海洋持续补给大气水汽，干燥陆地不再无条件吞掉经过的湿空气；降水只扣除一次水汽。土壤储水由液态雨水与融雪补充，蒸发和径流消耗。植被分类参考半年降水趋势，避免短期少雨立即变成荒漠；天然干旱区仍会存在，湿润期可逐渐恢复。

自转、画质与存档

自转与文明日期分开演示，温度蓄热跟随自转时钟；暂停冻结自转与天气。温室强度可在行星参数页调节。河岸网格分批生成，地质更新等待当前网格完成。新版 JSON 保存日夜蓄热和天气时钟，兼容 v1–v4；PNG 导出保持可用。需在支持 JavaScript 和 WebGL 的浏览器中打开本 HTML。

文明与操作

在「文明」页投放人类，或播种四个文明。5× / 20× 可更快看到扩张。全面战争支持行军、占领、首都迁移与兼并；航海能力决定能否跨海。小人为代表性单位，不是逐人完整 AI。地质时钟独立加速，可改变海岸和河网。空格 暂停，1 观察，2 投放，M 地图切换，F 聚焦，H 沉浸，Esc 退出工具 / 关闭面板。

保存、导出与兼容

每次打开随机生成新世界；相同种子复现初始条件。保存 JSON 可保留进度，支持载入原版 v1 存档。PNG 导出包含地形、体积云、河流和叠加图形，不包含控制面板。请使用能够执行 JavaScript 和 WebGL 的浏览器打开；聊天附件的静态预览不能代替浏览器。云质量可调，自适应模式降低采样分辨率以保护性能；WebGL 不可用时明确切换到无体积云的 Canvas 兼容模式。
