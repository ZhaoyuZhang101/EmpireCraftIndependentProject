# Perf3.1 实现与数据约定

## 单一世界数据

`WorldData` 是权威二维世界。高度编辑/新生成 → 海水检测 → `FlatClimate.Build` → `FlatHydrology.Build` → `FlatTerrainAnalysis.Build` → 群系与肥力、文明有效性检查 → 主线程事务安装。

`FlatTerrainFacts` 是派生缓存，不改变 v1 二进制存档布局。渲染、图例、选区诊断、局部水面与摄影星球都从同一份缓存读取。克隆世界时派生数组也深复制，防止后台重建写到当前显示世界。旧存档解码的 `updateBiomes=false` 保留其原群系和肥力；用户明确重算才更新。

地形生成仍使用原大陆、群岛、超级大陆、内海预设以及种子噪声。**随机的是海拔形状，群系和材料分类不是额外随机刷色。**

## 分类分层

Köppen 分类器输入为 12 个月平均温度与月降水。现有 30 类采用 0°C 的 C/D 分界及合并的 Aw；不是把地貌当成 Köppen 分类。本项目没有接入观测数据集，也不把几个月天气直接当成真实长期气候。

`Gradient` 是最大四邻格高度差（m/Tile），`Relief` 是5×5邻域最高减最低（m）。不把 m/Tile 谎称为实际坡度角。极地邻域不越界，东西周期连接。

## 排水与河湖

四邻格 Priority-Flood 从海面开始；没有海洋时从最低格开始。用填洼水面构建父节点先于子节点的顺序，再优先选更早节点中的最大真实水面落差。等水面平地保留确定性的溢出口路径，不制造无限循环或用 epsilon 改动20档地面高度。

反向排水秩累加上游径流。数值来源仍是原模型年降水/1200的相对汇流单位，**不是 m³/s 实测流量**。阈值 `max(18,TileCount/2600)`。相邻节点的水面头非增，不表示每条河段都必须有可见高差；湖面与平原允许等水面排水。

任意正填洼深度都标为湖泊，不再留出“看似陆地但河流需爬坡才能出洼地”的路径。海/湖深取水面减床面。河道宽度和河深由汇流代理估算，河深0.5–12m、半宽0.15–0.43 Tile，作为水面渲染参数，不偷偷改变作者海拔档位。没有实现水动力侵蚀地面。

连接掩码编码西/东/南/北四边；每格中心到实际连接边的圆滑通道距离场构成河面，邻格半宽插值使共同边一致。自然/文明视图不会用 LineRenderer 绘制河流描边，也不把整格河流变成矩形蓝块。河滩/海滩是距离场外的材料混合，不是黑白线条。

## 河口、泥沙与淡水

侵蚀/输沙代理由年雨、邻格落差、群系覆盖和上游汇流得到；流经湖泊时传递约12%的代理负荷。河流遇海洋的实际下游节点才生成河口。扇形长度4–16 Tiles随汇流变化，宽度沿流向扩展，高斯横向衰减与纵向指数衰减生成混合浓度。

扩展队列只能通过扇形内部连通海水，禁止跨陆地直接涂色；多个河口合并取较大代理浓度。淡水比例和悬沙值是0–1显示量，**不是盐度PSU、泥沙mg/L或严格物质输运方程**。因而现在可见河口淡水/悬沙渐变，不声称有密度分层、潮汐回推、真实冲积造陆或三角洲分汊演化。

## 两个上游项目的实际接入

`FlatShallowWater.cs` 采用 Unity-SWE 所展示的浅水高度/压力与通量更新思路，改为现有项目可用的托管CPU共享面有限体积扰动求解。限制出流不超过供体可用水量，采用自适应CFL步长，干格边界反射，平衡扰动按钮通过重分配水量产生波纹。默认64×64，10Hz，最多一个后台任务，不调用Unity对象API；主线程只上传法线/泡沫RGBA纹理。

它围绕权威河湖的静态基准水面求扰动：基准水头已扣除，`Bed=-restDepth`。全球水流方向由排水图负责，不把全局河床大落差作为局部初始压差再次加水。不求全球海洋、气候或文明，不从局部状态反写全世界水量。

只在2D自然/文明/水体视图、放大≥8 px/Tile且开关打开时激活；摄影不跑SWE。局部显示标尺100m/Tile，25m/子格，不是全球经纬地图的测地分辨率。最大子步与追帧时间有界；远景/故障降级到按实际流向平流的程序波纹。初始及按钮扰动触发波传播，没有承诺持续外部风强迫或完整速度平流。

`HPWaterOptics.cginc` 从 HPWater 的 `CaculateScatteredLight` 与 Schlick 反射函数改写，使用安全消光、Beer透射和单段均匀介质散射，按估算/实际水深、淡水比例、悬沙代理改变吸收散射系数。该模块实际被平面水面和原星球共享水着色路径调用，不是只附链接。

上游HDRP的屏幕空间反射/折射、RenderGraph、多MRT、完整水下体积积分/焦散没有移植。Built-in 的本次版本没有这些依赖。

## 等高线与渲染

`_GeoTex.r` 保存高度（m）。双线性插值后的高度生成100/200/500/1000m等高线，五倍间隔加深；导数抗锯齿，完全平坦处不涂满整块，缩小到<4 px/Tile时不显示。等高线只是同一高度场的可视化，排水不依赖线条像素。河水/海水上不画地形等高线。

地表类别用Point采样，不用平滑纹理抹糊全部Tiles；水体和河口浓度单独插值。数据纹理：A=深度/流向XY/半宽；B=岸距/悬沙/淡水比例/连接位；Geo=高度/材料/水桶湿度/排水高差。地形版本变化才上传新派生数据，人口更新不反复烘焙地形。

2D地图一张矩形网格，无逐Tile对象。只读星球沿用原球面资源并绑定相同三张派生纹理；局部SWE纹理在星球编译路径排除。项目源码的星球片元路径声明16个采样器；这只是静态库存，不替代Unity后端是否裁剪/编译成功的证明。

## UI与线程边界

六组标签页复用现有UITK，标签按点击显示对应面板，组内Foldout可展开。原工具、层、保存加载、导入导出、文明、摄影、暂停与键盘入口均保留。动态tab/panel配对单独加入源码回归，避免静态正则只检查了字面量按钮。

生成、气候、排水、地貌属于明确用户操作后的后台计算；没有加入实时板块运动。Unity纹理、材质与视觉元素只在主线程触碰。生成失败不替换当前世界；局部波动失败降级，不销毁存档。
