# V4.2 Repair IPCFix1 NightLighting Fix 2

问题：夜侧出现明显绿色大气圈。

原因：旧的 `_OrbisAirglowColor = (0.070, 0.180, 0.105)` 绿色通道占优，且体积积分在大气切线产生 limb brightening。

修复：
- 气辉颜色改为低饱和蓝灰 `(0.014, 0.020, 0.028)`。
- 向下气辉系数 `0.035 -> 0.018`。
- 高空气辉体积发光增加 `0.42` 的 limb-safe 缩放。
- 不改月光、夜间天光、IPC 循环结构、天气/云运动。

目标：夜侧保留非常弱的大气层次，但不再出现霓虹绿色完整光圈。
