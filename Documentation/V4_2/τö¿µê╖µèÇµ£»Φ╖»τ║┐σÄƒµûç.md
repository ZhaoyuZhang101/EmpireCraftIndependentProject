# ORBIS V4.2 全球大气技术总结

## 核心目标

将 ORBIS 从“Weather Map + 噪声驱动体积云”升级为：

**全球气候动力学 → 分层大气 → 云微物理 → 降水/雷暴 → GPU 体积渲染。**

核心原则是：**气候模拟决定哪里有云、云是什么类型、有多高以及何时生成和消散；Shader 只负责把物理状态可视化。**

## 1. 当前瓶颈

V4.1.x 已有全球温度、气压、湿度、风场、垂直运动、水汽输运、大气散射和体积云基础，但仍偏二维/2.5D：

- 云仍容易表现成移动噪声。
- 某些区域长期有云，另一些区域长期无云。
- 云底、云顶和厚度仍受渲染参数强控制。
- 缺少垂直温湿结构。
- 积云不能依据热力条件连续发展成积雨云。
- 降雨没有形成完整的云水质量转换闭环。
- 雷电不应是随机特效，而应来自成熟雷暴。
- 云对辐射、温度和后续天气的反馈不足。

因此下一阶段应建设 **Reduced-Order Global Atmosphere（实时简化全球大气模型）**。

## 2. 主要技术参考

### ClimaAtmos

学习全球球面网格、温度/压力/密度/水汽耦合、湍流与对流、云微物理、辐射以及质量/水/能量守恒。不要直接把完整 Julia 数值模型塞进 Unity，而应提炼适合实时游戏的结构。

参考：<https://github.com/CliMA/ClimaAtmos.jl>

### CloudMicrophysics / WRF

把大气水拆成：

| 变量 | 含义 |
|---|---|
| `qv` | 水汽 |
| `qc` | 云液水 |
| `qi` | 云冰 |
| `qr` | 雨水 |
| `qs` | 雪 |
| `qg` | 霰 |

主要转换：

```text
qv → qc       凝结
qc → qv       云滴蒸发
qv/qc → qi    冰化/沉积
qi → qv       升华
qc → qr       自动转化为雨水
qc + qr → qr  碰并增长
qi → qs       冰晶聚合为雪
qi/qs → qg    强对流混合相过程
qs/qg → qr    暖层融化
qr → qv       雨滴蒸发
```

参考：
<https://clima.github.io/CloudMicrophysics.jl/>
<https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/physics.html>

### Horizon Zero Dawn / Nubis

视觉层继续采用宏观云场、Perlin-Worley、Worley 侵蚀、Ray Marching、Beer-Lambert 消光、多重散射近似、云影和时间重投影。

关键变化：**宏观云场必须来自气候模型，噪声只负责小尺度细节。**

参考：<https://advances.realtimerendering.com/s2015/>

## 4. 垂直大气

不建议只分 Low/Mid/High 三层。第一阶段推荐约 **12 层**：

```text
L11  12–16 km   对流层顶 / 卷云
L10  10–12 km   积雨云砧 / 云冰
L9    8–10 km   高层冰云
L8     6–8 km   高云
L7     5–6 km
L6     4–5 km   中层云
L5     3–4 km
L4     2–3 km
L3   1.5–2 km   积云发展层
L2 0.8–1.5 km   边界层
L1 0.3–0.8 km   低层
L0    0–300 m   地表层 / 雾
```

每个 `(lat, lon, layer)` 至少保存：

```text
T, P, rho
qv, qc, qi, qr, qs, qg
u, v, w
cloudFraction
turbulence
```

## 5. 热力学与饱和

基础关系：

```text
dP/dz = -rho * g
P = rho * R * T
RH = qv / qsat(T, P)
```

当 `RH >= 1`：

```text
qv → qc
```

并释放潜热。

空气上升时压力下降、膨胀冷却、RH 上升；空气下沉时压缩增温、RH 下降。因此云的生成与消散必须和垂直运动耦合。

## 6. 全球风场与垂直运动

风至少受以下因素控制：

```text
Pressure Gradient
+ Coriolis
+ Surface Friction
+ Thermal Gradient
+ Topography
```

垂直速度：

```text
w =
  convergenceLift
+ thermalBuoyancy
+ orographicLift
+ frontalLift
+ stormUpdraft
- highPressureSubsidence
```

这样才能形成移动高低压、锋面、季风、迎风坡云雨、背风雨影以及真实迁移的对流区。

## 7. 云必须来自物理状态

不要再让：

```text
cloudCoverage = noise(...)
```

直接决定云。

正确链路：

```text
Atmospheric State
→ Saturation
→ Condensation
→ qc / qi
→ Cloud Fraction
→ Rendering Density
```

最终渲染：

```text
density =
physicalCloudDensity
× shapeNoise
× erosionNoise
```

低层可形成 Stratus、Fog、Shallow Cumulus；中层形成 Altostratus/Altocumulus；高层主要由 `qi` 形成 Cirrus。

**Cumulonimbus 是贯穿多个垂直层的深对流柱，不属于单独固定云层。**

## 8. CAPE/CIN 与积雨云

建议实现简化 parcel model：

```text
Surface Heating
→ Warm Moist Parcel
→ Rise
→ Adiabatic Cooling
→ RH 100%
→ LCL
→ Condensation
→ Latent Heat
→ Buoyancy ↑
→ w ↑
→ Cloud grows upward
```

强不稳定条件：

```text
High qv
+ High SST/Surface T
+ Low-level Convergence
+ High CAPE
+ Weak CIN
→ Cumulus
→ Congestus
→ Deep Convection
→ Cumulonimbus
```

`cloudTopHeight` 应成为模拟结果，而不是 Shader 常量。

## 9. 积雨云生命周期

```text
CUMULUS → DEVELOPING → MATURE → DISSIPATING
```

Developing：强上升、`qc` 增长、云顶快速升高。

Mature：同时存在 Updraft、Downdraft、Rain、Ice、Graupel、Lightning，可形成主塔、砧状云、overshooting top 和降雨核心。

Dissipating：下沉和降水占主导，上升气流衰弱，云体逐步蒸发。

## 10. 降水与冷池

降雨来自云水：

```text
qc > threshold
→ autoconversion
→ qr
```

雨水进入未饱和空气：

```text
qr → qv
→ Evaporative Cooling
→ Negative Buoyancy
→ Downdraft
```

冰相：

```text
qc/qv → qi
qi → qs
qi + supercooled water → qg
qs/qg → qr（暖层融化）
```

冷池反馈：

```text
Heavy Rain
→ Evaporation
→ Cooling
→ Downdraft
→ Surface Cold Pool
→ Gust Front
→ Lift Warm Moist Air
→ New Convection
```

这样第二代雷暴可以由第一代雷暴触发，而不是随机刷出来。

## 11. 雷电与雷声

成熟雷暴单元保存：

```text
StormCell
{
  CAPE
  updraft
  cloudWater
  cloudIce
  graupel
  cloudTop
  precipitation
  charge
}
```

游戏级电荷近似：

```text
chargeGeneration ∝ qi × qg × |w| × mixedPhaseFactor
```

达到击穿阈值后产生 IC（云内）、CC（云间）或 CG（云地）闪电。

雷声必须来自同一个闪电事件：

```text
delay = distance / speedOfSound
```

近地可先使用约 `343 m/s`，之后再根据温度修正。

## 12. 云—天气双向反馈

系统必须从：

```text
Climate → Clouds
```

升级为：

```text
Climate ↔ Clouds
```

例如：

```text
Cloud Optical Depth ↑
→ Surface Solar Heating ↓

qv → qc
→ Latent Heat Release
→ Buoyancy ↑

qr → qv
→ Evaporative Cooling
→ Downdraft
→ Cold Pool
```

云必须反过来改变天气。

## 13. 海洋、陆地与季节

关键循环：

```text
SST → Evaporation → qv → Convection
```

海洋需要热容量和洋流输运；陆地需要土壤水分、蒸散、积雪和不同热容量。

轴倾角和太阳直射纬度变化进一步影响 Hadley Cell、ITCZ、季风、海冰/积雪、风暴路径和全球云带。

## 14. 与大气穿越系统结合

同一个天气系统必须从太空一直连续到地表：

```text
Orbit
→ Global Cloud Bands
→ Cirrus / Cumulonimbus Anvil
→ Cloud Tower
→ Inside Storm
→ Lightning
→ Cloud Base
→ Rain Shaft
→ Surface
→ Rain + Wind + Delayed Thunder
```

不能在不同高度切换另一套独立天气特效。

## 15. GPU 接口

模拟层建议输出：

```text
Atmosphere3D:
T, qv, qc, qi
cloudFraction
wind
verticalVelocity

Precipitation3D:
qr, qs, qg

StormData:
cellPosition
cloudTop
updraft
charge
lightningEvents
```

Shader：

```text
physicalDensity = f(qc, qi, cloudFraction)
detail = PerlinWorley * WorleyErosion
density = physicalDensity * detail
```

不同高度读取对应层，而不是把一张二维 Weather Texture 拉成整个云柱。

## 16. 性能策略

不能完整照搬 WRF/ClimaAtmos。采用多尺度 LOD：

```text
Global Physics = coarse
Local Weather = medium
Visible Clouds = high detail
```

全球尺度低分辨率、低频更新；玩家附近和强天气区域提高分辨率与更新率；只有活跃 StormCell 才计算 CAPE、Downdraft、Cold Pool、Graupel、Charge 和 Lightning。

渲染层继续使用 half resolution、temporal reprojection、adaptive ray steps、early exit 和 cloud-shadow cache。

## 17. 守恒原则

明确追踪：

```text
Total Water = qv + qc + qi + qr + qs + qg
```

水只能通过蒸发、凝结、降水和地表储水/径流在不同库之间转移，不能由噪声凭空产生或消失。

长期模拟至少尽量保持：

- 质量守恒；
- 水守恒；
- 能量近似守恒。

这是避免运行数小时/数天后气候漂移的基础。

## 18. 推荐开发顺序

### Phase A — Atmosphere Core

1. 12 层大气柱；
2. T/P/rho 垂直结构；
3. qv/qc/qi；
4. u/v/w；
5. 球面水平输运；
6. 垂直输运；
7. 饱和凝结；
8. 潜热。

这一阶段先不急着做闪电。

### Phase B — Cloud Microphysics

增加 `qr/qs/qg`，完成雨、雪、云冰、降水下落和蒸发冷却。

### Phase C — Deep Convection

增加 CAPE、CIN、LCL、深对流、积雨云生命周期、Downdraft、Cold Pool 和 Gust Front。

### Phase D — Storm Electricity

增加混合相起电、StormCell、IC/CC/CG 和雷声传播。

### Phase E — Rendering Integration

让现有体积云直接读取分层 `qc/qi/cloudFraction`；雨雪读取 `qr/qs/qg`；云影、大气散射和地表光照共享同一气象状态。

## 19. V4.2 的验收标准

不要只验收“画面更漂亮”，而应验证：

1. 原本晴空区域能在天气条件变化后自然生成云。
2. 原有云区可以自然消散。
3. 云团随真实风场迁移，而非仅纹理 UV 移动。
4. 高、中、低层云具有不同高度和风速。
5. 积云能从低层逐步长成深对流。
6. 积雨云能产生降雨、下沉气流和冷池。
7. 冷池可以触发新对流。
8. 雷电只在满足雷暴条件时高概率发生。
9. 从太空下降到地表看到的是同一个天气系统。
10. 长期模拟中的总水量和平均能量没有不可接受的漂移。
11. 展开地图、球体和近地视图读取同一份全球天气状态。
12. 云的宏观存在性不由噪声随机决定。
