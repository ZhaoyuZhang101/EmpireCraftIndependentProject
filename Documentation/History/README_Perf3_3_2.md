# ORBIS Perf3.3.2 — 雲層、河口與聚焦修復版

這是以上一版 Perf3.3.1 合併工程為基礎的完整 Unity 工程，不需要再套用原來的 Scroll Patch。

**狀態：源碼修復與離線回歸已完成；尚未在 Unity Editor 編譯、Play Mode 或 D3D11 實機驗證。沒有實測 FPS。** 本版的測試圖使用受控合成資料，不能當成遊戲截圖或成品美術保證。

## 開啟

1. 解壓，將 `ORBIS_TerrainPerf3_3_2_VisualRepair` 加入 Unity Hub。
2. 使用 **Unity 6000.0.47f1，Built-in Render Pipeline**。
3. 開啟 `Assets/ORBIS/Scenes/Orbis2DWorld.unity`，進入 Play Mode。
4. 可以載入原有世界存檔；本版沒有修改存檔格式、人口、領土或權威海拔資料。

## 對應截圖的修改

| 問題 | 本版修改 |
|---|---|
| 球體雲層幾乎不可見 | 球體體積採樣改讀與 2D 共用的氣候雲況圖；雲底直接查詢同一份地形高度，避免使用另一套球體高度和稀薄的月氣候快照 |
| 2D 雲圖放大成模糊方塊 | 完全展開後使用相應經緯度的徑向體積柱，讀取三維形狀噪聲、積分消光、光照與自陰影；不再把密度缓存直接當作最終雲色貼圖 |
| 河流入海／入湖封口 | 根據河道連接位延伸到第一個面狀水域格中心，跨過重建海岸線；GPU 水域遮罩與 CPU 局部水域採樣同步修正 |
| 樹木缺角 | 以樹根的地形、河道及設施資料決定整棵樹是否存在；樹冠不再逐像素依照地形密度被截掉，並可以覆蓋相鄰行 |
| 樹形過度重複 | 增加樹冠簇、樹高與色調變化；寒冷大陸氣候使用分層針葉樹輪廓。仍是程序化美術，不是完整手繪圖集 |
| 高差呈現橫線、針狀線 | 移除格邊高差條紋；較陡的朝南坡面以連續高度場生成岩層與陰影，詳細圖淡出製圖用等高線 |
| 球體聚焦後 2D 回到中央 | 移除進入 2D、Focus 及視窗約束中的緯度重設；聚焦保留同一經緯度，經過區域總覽尺度再進入詳細圖，鏡頭朝向平滑收斂 |
| 球面尖峰與極點不一致 | 顯示海拔係數從 0.00001875 降至 0.000006；極點使用該極區一行資料的平均顯示海拔，在最後一行內平滑收斂；點選、雲底及地表共用同一換算 |
| 1024 寬世界球面漏採樣 | 球面格網上限提高到對應 1024 欄；平面仍是每張 4 頂點的共享四邊形，沒有把完整球面網格留在 2D 畫面中 |

## 操作

- 球體向內滾輪：以當前落點展開；繼續縮放進入詳細圖。
- 球體點選後按 **F**：將選中格保留在落點，進入詳細圖。
- **M**：球體／平面切換，可反轉過渡；從詳細圖退出會先縮回总覽。
- 拖動／WASD：平移，東西環繞；南北邊界不互接。
- **2D 總覽**：在平面縮小到總覽；從球體進入時保留落點，不跳到地圖中央。
- **G / C**：網格／等高線。詳細圖的製圖等高線會淡出。

靠近極點時，為了保留選區在畫面中央，視窗可能顯示地圖之外的背景。這是有界緯度視窗，沒有把南北極錯誤連接。

## 雲層與性能

雲況圖是 **256×128 / 512×256 / 1024×512，最高 5 Hz** 更新的密度來源，三維噪聲按時間連續採樣。球體與平面使用同一雲況及同一地形來源。極區氣候在最後一行收斂，避免經度在極點分裂。

體積緩衝區按畫質使用視窗線性尺寸的 50% / 65% / 80%，地表不跟著降解析度。分開保存散射與透射率後合成。詳細圖降低遮擋強度，讓地表保持可讀；來源資料不變。過渡中體積權重接近零時跳過體積積分。

增加雲層品質會增加 GPU 負擔。本版保留有限採樣預算、提前結束、單一密度缓存、地表共享網格及原有缓冲區複用，不能以離線軟體渲染結果推算實際 FPS。

## 從 CK3 文件吸收的部分與界線

已用在本版的是：共用地形查詢、獨立雲層合成、按縮放調整資訊與細節，以及保留區域 ID 和地形資料的分離。没有引入文件中的 URP 管線或將固定 LOD 當成動態 LOD。

世界仍採用 2:1 經緯矩形資料。球體是同一份 2D 資料的顯示拓撲，不會另行生成地形。**這能保證位置與資料一致，不能讓矩形平面和球面同時保持面積、角度、距離全部無失真。** 極區的經向壓縮仍存在；本版處理的是過度高度誇張、極點半徑和資料採樣問題。

雲層是月氣候驅動的視覺體積，不是新加的即時水汽微物理模擬。展開過程使用球體體積、地表過渡雲層與平面體積柱的交叉淡化，不宣稱同一三維流體被精確拉平。樹木、房屋仍屬程序化顯示；可互動局部區塊、碰撞、居民、串流存檔與 CK3 曲線地名不在本次修復中。

## 驗證

本版結果只看 `Validation/Perf3_3_2/`；其他版本目錄與舊報告保留作為歷史，不是本版的驗收證明。

已執行：
- 89 份 C# 語法解析、資源／include／GUID／介面連接檢查；不是 C# 語義編譯。
- 682,094 項轉譯到 C++ 的數值斷言，包括四方向、不同河寬、經度接縫的河口連續性與禁止切開無關陸地。
- 真實源碼函式轉譯到 GLSL ES 後，在 Mesa 上編譯及執行：地表、樹木、岩層、球面位移、雲密度與雲內光照採樣。
- 合成河口中心線覆蓋率為 255/255；雲況跨一圈的最大差異為 1/255；關閉雲密度後消光為零。

仍需 Unity 驗證：
1. `Tools → ORBIS → Perf3.3 → 2 Report shader import messages`。
2. 在 Play Mode 執行 `4 Verify repaired globe focus in Play Mode`：測試四個落點（含高緯與接縫），確認落點和三圈水平平移後的 Tile ID。測試暫停模擬、改變視角，結束後恢復暫停狀態。
3. 用你原本的世界存檔回到七張截圖的位置，檢查球體／展開中／總覽／詳細圖以及暫停、晝夜、畫質切換。
4. 用 Unity Profiler 比較不同畫質的 CPU、GPU 時間與記憶體；本環境沒有執行這一步。
