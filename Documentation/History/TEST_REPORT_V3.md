## Unity 内测试入口（待执行）

导入完成且 Console 无编译错误后，运行：

- `Tools → ORBIS → V3 → 驗證核心與存檔`：确定性、天气边界、冻结、常量插值、V3 天气保存延续，以及两种旧 V2 的**合成字段样例**。合成样例不是用户真实存档。
- `Tools → ORBIS → V3 → 驗證著色器與資源`：资源和 Shader 错误检查；不取代画面检查。
- Play Mode 中 `Tools → ORBIS → V3 → 檢查目前近景`：相机高于采样地表，中心射线可以拾取。
- Play Mode 中 `Tools → ORBIS → V3 → 切換全解析度大氣對照`：判断低分辨率体积放大引起的差异。

原有 `驗證世界模擬` 菜单也保留，用于文明/水文/远征回归；此次同样未运行。无图形设备的 batchmode 即使脚本测试通过，也不应标为 GPU 验收通过。

## 画面与交互验收矩阵（全部待执行）

| 场景 | 操作与应检查的结果 |
|---|---|
| 白昼海面、夜侧、晨昏边界 | 同一种子冻结天气比较空气开/关；地球应遮挡太阳，夜云不应无条件自发光 |
| 从轨道进入云层再到地表 | 缓慢与快速滚轮各测试；云壳区间不应突然整层消失；相机不应落入地形 |
| 山脊/河口/海岸近景 | 开关细分与全解析度对照；检查天空向地面漏色、交接孔洞、重复层和闪烁 |
| 赤道、两极附近、六面交界 | 拖动近景与拾取；检查局部坐标稳定、选区正确、材质不沿经线拉长 |
| 地表 → 全景地图 → 地表 | 开启自转后切换；检查关注地点恢复及新选区更新 |
| 海洋、湖泊、河流 | 切换 V2 水体；检查河口法线、颜色与反射连续，河流不是单纯贴色线 |
| 风/水汽/洋流轨迹 | 相对地表检查方向，确认无重复自转；暂停应冻结；诊断需要时关闭云 |
| 全陆与全海极端世界 | 洋流轨迹不应在全陆世界无限重置；云/雨/高度保持有限 |
| V3 保存恢复 | 暂停后保存，退出再载入；比较地点、时间、天气库和下一步演化 |
| 两种原 V2 用户存档 | 分别备份后加载，确认迁移来源与地块/人口；不覆盖旧档 |
| 低/中/高/最高画质 | 用 Unity Profiler 记录 CPU/GPU 时间；检查 RenderTexture 回收，不把目标 FPS 当实测值 |
| D3D11 / Metal / Vulkan 等 | 分别验证画面上下方向、深度、MRT 与全分辨率参考一致性；未承诺全部 API 支持 |

当前深度路径面向原有不透明地形。透明覆盖层与云的先后遮挡是近似，输运线可以被云遮住。没有接入完整透明物体体积深度排序。
