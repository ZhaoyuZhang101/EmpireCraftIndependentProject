# ORBIS VI.3 — Unity 中文 Demo

以 `ORBIS_VI_1.html` 為基礎移植的原生 Unity 星球文明沙盒。使用 C#、Mesh、UI Toolkit 與自訂 Shader；世界資料採用四邊形 Tile → 自然 Zone → 地形 Chunk。

**本包包含本輪完成的程式與素材。此工作環境未連上你本機的 Unity Editor，尚未通過 Unity 編譯、Play Mode 或 GPU 實測，也未產出 Windows 執行檔。** 不宣稱已完成原版所有細節的一比一複刻；具體差異見下方移植範圍。

## 開啟與更新

1. 將 ZIP 解壓到新資料夾，保留整個 `ORBIS_Unity` 結構。
2. Unity Hub → Add project from disk，選擇 `ORBIS_Unity`。
3. 使用 Unity 6（6000.x）開啟。專案標記版本為 `6000.0.47f1`；已有其他 Unity 6 版本時，可以由 Hub 選擇該版本升級開啟。
4. 等候匯入後，開啟 `Assets/ORBIS/Scenes/OrbisDemo.unity`。選單 **Tools → ORBIS → 開啟示範場景** 也可開啟。
5. Game 視窗選擇 1600×900 或 16:9，按 Play，點「播種四個文明」。
6. 先執行 **Tools → ORBIS → 驗證圖形與中文字型**，再依 `Documentation/實機驗收.md` 檢查畫面。

本版使用 **Built-in Render Pipeline** 與線性色彩空間，自訂 Shader 尚未移植到 URP/HDRP。首次初始化會設定此專案的公司名稱、產品名稱、視窗尺寸及色彩空間。沒有付費素材、後端服務或第三方 UPM 依賴。

若替換之前的 Demo，建議解壓到新目錄後開啟，避免沿用過期匯入結果。Unity 專用 v1 存檔可遷移；HTML 原版存檔不能直接互載。

## 本次視覺升級

| 部分 | 本版實作 |
|---|---|
| 連續地形 | 每個基礎三角形細分為 64 個，總計 **442,112 個地表三角形**；共用邊界用整數重心座標焊接位置與法線，減少粗面與裂縫。 |
| 山體與材質 | 增加種子決定的山脊／細節位移，河谷保留切割；Image Gen 草地、砂土、岩石、雪地紋理採三向投影，附微表面法線擾動。 |
| 體積雲 | 讀取同一套雲量、濕度、溫度、降水與三維切向風場。溫濕度控制雲底與對流厚度；雲形使用 64³ 週期性噪聲體積。 |
| 風與雨帶 | 平滑信風／西風／極地風帶，加入季風、壓力梯度、科氏偏轉，以及八組種子決定的移動低壓系統。低壓同時影響風場、降雨、雲量。 |
| 雲的移動 | 每個 Tile 積分實際風向，Shader 使用積分位移與逐幀外插；關閉風場強度後停止平流，雲仍可凝結或消散。雲影取樣同一雲密度函式。 |
| 晨昏線 | 地軸傾角、季節、自轉和同一太陽方向決定日夜分界。地面採連續日照過渡與低太陽高度的光譜衰減。 |
| 大氣 | 統一雲／大氣光線步進，加入 Rayleigh、Mie 單次散射、光學厚度、行星遮光與 RGB 透射合成。平均氣溫影響尺度高度，日照參數影響輻射亮度。 |
| 旋轉與相機 | 模擬維持固定時間步，顯示旋轉逐幀外插並平滑；拖曳、縮放、地圖平移加入阻尼。新增跟隨地表與自動環繞。 |
| 更新負載 | 地表顏色分批更新 Chunk；沒有每隔幾秒重建整球的排程。地形編輯或分區重劃仍會觸發完整網格重建。 |

大氣與雲在自然／文明圖層顯示；數據圖層直接呈現資料。地圖上的雲是同一密度場的投影合成。雲與大氣可分別開關。

這是適合遊戲星球的簡化單次散射模型，尺度高度經過誇張，並非 Bruneton 多次散射 LUT 的完整移植。雲畫質提供 32／56／80 步及依解析度選擇；尚無時間重投影、半解析度升採樣、近地 LOD 或效能保證。

## 四邊形 Tile、Zone、Chunk

| 層級 | 行為 |
|---|---|
| Tile／地塊 | Cube-sphere 六面各 24×24，共 **3,456 個實際四邊形**。每個 Tile 有四個角與四個鄰居，六面共享邊界。 |
| Zone／自然區域 | 同一 Chunk 內相鄰、地貌一致的連通區：遠洋、海岸、湖泊、河谷、高地、冰原、荒漠、草原與森林。 |
| Chunk／地形區塊 | 先按海陸連通性分開，再按流域分水嶺、山脊、海岸、地形高差的穿越成本生長。每個區塊有獨立 Mesh、Renderer、包圍盒與球背面剔除。 |

「四邊形地塊」顯示真實 Tile 邊界；「自然區域」和「地形區塊」顯示分組。陸地約 110 Tile、海洋約 220 Tile 是尺度參考，不是硬性上限。小島可保持獨立。

全部模擬資料仍常駐記憶體；Chunk 尚未使用磁碟串流、Addressables 或 Jobs/Burst。

## 中文與操作

介面、地名、文明名稱、事件、說明和主要錯誤訊息已改為繁體中文。內嵌完整 Noto Sans CJK TC 字型，字元覆蓋檢查結果見 `Documentation/Validation-Results.json`，授權見 `Documentation/Noto-License.txt`。目前是單一中文介面，沒有語言切換器或 Unity Localization 多語表格。

| 操作 | 用途 |
|---|---|
| 拖曳／滾輪 | 環繞星球、平移地圖／縮放 |
| 點擊地表 | 選取地塊或執行工具 |
| M／F／H／空白鍵 | 星球地圖切換／聚焦／面板／暫停；先點一下地表取得焦點 |
| 當地地圖／尋找主河 | 放大選取地區／定位主要河流 |
| 投放人類／播種四個文明 | 建立一個或多個新文明 |
| 降雨／隆起陸地／沉降海洋 | 改變環境；高程變化重算排水及自然區域 |
| 派出拓荒隊／派出遠征軍 | 從有足夠人口的己方地塊派遣，依實際路線移動 |
| 全面戰爭／停戰 | 開戰／召回遠征軍；可切換自動邊境戰爭 |
| 風向／洋流／國界／地名 | 獨立顯示觀測標記 |
| 雲層／雲影／大氣／晝夜 | 分別檢查雲、陰影、散射、日夜光照 |
| 自轉／跟隨地表／環繞觀察 | 自轉、固定地區觀察、相機自動環繞 |
| 1／5／20 倍速 | 日曆演化速度；自轉及天氣有獨立的即時時鐘 |
| 保存世界／載入 | 保存或恢復世界、遠征隊、分區、參數與視角 |

遠征使用四鄰接 A*，成本包含高程、山脊、流域分界、積雪和海路。科技達到 2 的航海時代可跨海；軍團需要戰爭狀態。路線受阻時重算或返鄉，補給中斷則逐漸損耗。派遣會從聚落扣除對應人口，人口統計包含在途隊伍。

可選目標：至少四個存續文明、人口五千、平均溫度 5–28°C，在和平狀態維持 360 日。完成後可繼續沙盒。

## 保存、驗證與建置

- 使用 `Application.persistentDataPath`；直接點「存檔資料夾」可開啟。
- Windows 預期位置：`%USERPROFILE%\AppData\LocalLow\ORBIS\ORBIS Unity Demo\`。
- 本版存檔為 `orbis-demo-v2.json`，覆寫前保留 `.bak`。若沒有 v2，載入時會尋找 v1 並遷移新增設定。
- 存檔驗證包含數值範圍、地塊歸屬、分區連通性與軍團路徑。HTML 原版使用不同拓撲，不能直接載入。
- **Tools → ORBIS → 驗證世界模擬**：種子、四鄰接、水文、連通分區、長期氣候、零風平流、太陽座標、航海路線、派遣人口守恆、存檔與 v1 遷移檢查。
- **Tools → ORBIS → 驗證圖形與中文字型**：檢查 Shader 匯入錯誤、GPU 支援、字型、材質及雲體積資料。
- **Tools → ORBIS → 建置 Windows 示範版**：需要該 Editor 的 Windows Build Support。分享時保留完整輸出資料夾。

以上 Editor 檢查已附在專案中，本次未執行。離線檢查僅覆蓋 C# 語法、資源引用、中文字形、拓撲／焊接與太陽座標數值，不等同 Unity 編譯或實機畫面驗證。

## 與 HTML 原版的差異

已涵蓋：種子地形、板塊推進、河流與湖泊、風與洋流、移動低壓、溫度與晝夜蓄熱、雲與散射、文明成長／擴張、實體遠征路線／航海／戰鬥、地理命名、星球與平面地圖、觀測與干預、保存／載入及中文介面。

仍有差異：球面與地圖採視圖切換，尚無原版的連續展開變形；當地地圖是平面放大，尚無傾斜地形透視；水量收支、文明經濟與戰鬥保留簡化模型，並未逐式搬運 HTML 的所有細節；沒有原版 WebGL 的低解析度雲緩衝與重建流程。四邊形拓撲也意味著相同種子不會與 HTML 每個地塊一一對應。

技術來源、採用內容及限制見 `Documentation/Shader-References.md`。原始 HTML 保留在 `Reference/ORBIS_VI_1.html` 供比對，不參與執行。

## 程式入口

- `OrbisDemo.cs`：啟動、時鐘、平滑視角、工具、存檔。
- `OrbisWorld.cs`、`OrbisAtmosphereModel.cs`：地形、水文、氣候、低壓與文明。
- `OrbisExpeditions.cs`：遠征路線、航海、戰鬥與返鄉。
- `OrbisMath.cs`、`OrbisGeography.cs`：四邊形拓撲、Zone、Chunk。
- `OrbisPlanetView.cs`、`OrbisWeatherField.cs`：細分網格、法線焊接、共享天氣貼圖。
- `OrbisMapView.cs`、`OrbisOverlays.cs`、`OrbisNames.cs`：世界地圖、觀測標記、地名。
- `OrbisHud.cs` 與 UXML／USS：中文 UI Toolkit 介面。
- `Surface.shader`、`Clouds.shader`、`WeatherDensity.cginc`：地形、晨昏、體積雲及大氣。

`Tools/generate_cloud_noise.py` 是可重現的數值體積生成器，執行遊戲不需要 Python。Image Gen 地形圖集及提示詞保留在資源與文件目錄中。
