# ORBIS TerrainPerf3.1 · Water / Climate / Terrain

**完整源码升级包，基于原始 Perf3：ORBIS_TerrainPerf3_2DWorld_Zone4x4_Full.zip。没有回退到 Perf2，也没有另起示例项目。**

已修改实际 Assets、运行时代码、着色器、界面、测试和文档。保留二维主模拟、4×4 Zone、20 档陆地高度、原有文明与存档、只读星球摄影。两个水体项目按现有 Built-in 架构适配，不导入 HDRP 工程覆盖本项目。

> **验证边界：本次没有运行 Unity Editor、原生 C# 编译器、D3D11 着色器编译、Play Mode、实机画面或 FPS。ZIP 是完整源码候选版，不是已验收成品或 EXE。已通过的是源码结构/连接检查与 C++ 数值转译回归，不能据此保证 Unity 零报错。**

## 打开

完整解压到新目录，在 Unity Hub 添加包含 `Assets`、`Packages`、`ProjectSettings` 的工程根目录。使用 **Unity 6000.0.47f1 / Built-in Render Pipeline**，不需要安装 HDRP/URP 或导入两个上游工程。

主场景：`Assets/ORBIS/Scenes/Orbis2DWorld.unity`。

先等待导入并查看 Console，再执行 `Tools → ORBIS → Perf3.1 → Run water climate and current-API validation`。在 Windows 中使用 D3D11 检查本次报错；菜单只验证当前图形 API，不会把 OpenGL/Metal 的成功当成 D3D11 成功。

命令行入口见 `Validation/WaterClimate/run_d3d11.ps1`。不要带 `-nographics` 来声称已验证 GPU 后端。

随后进入 Play。水文页点击“定位下一个河流入海口”可快速聚焦。地形页切换地貌/材料图层及等高线；气候页核对分类，选区数据可查看月温降水推导的年均值、湿润月数和排水高差。

## 本次实际改动

| 项目 | 已写入的实现 |
|---|---|
| Shader 报错 | 修复 FlatMap 的 `line` 保留字冲突；Surface 中相同命名一并修复。`step` 调用逐项检查两参数；新地图着色器保留原资源路径与 GUID。 |
| Unity-SWE 适配 | 单个可见区 64×64、10Hz CPU 工作线程浅水扰动求解器，守恒共享面通量、CFL 时间步、干岸反射与水量诊断。求解结果实际进入水面法线和泡沫。不是整个 HDRP/GPU/MacCormack 工程移植。 |
| HPWater 适配 | 从上游体积水光学函数适配散射、吸收/透射、Schlick 反射，实际接到河、湖、海和只读星球的水色。不是完整 SSR、折射缓冲或 RenderGraph 移植。 |
| 气候与地形 | 12 个月温度/降水 → Köppen → 群系；另算地貌、地表材料和土壤水分。雨林/沙漠/湿地/丘陵/高原等有独立依据与颜色代码。 |
| 河流与湖泊 | Priority-Flood 填洼水面、无环排水秩、较大真实水面落差优先、汇流、水平湖面；河流窄水面按上下游连接，不把整格涂蓝。 |
| 河口与岸滩 | 连通海水内扇形淡水/悬沙混合，按上游汇流和输沙代理量决定规模；沙滩、泥滩、砾石岸过渡。没有黑白河流外描边。 |
| 等高线 | 100 / 200 / 500 / 1000m 可选等高距，每五条加深；取真实高度数据，不从群系色块猜高低。 |
| UI | 世界、地形、水文、气候、文明、文件/摄影六页；组内折叠。保留原功能，并提供永久图层/工具选择、选区诊断和图例。 |
| 性能边界 | 不逐 Tile 建对象；派生水文贴图只在地形版本变化后上传；近景才启用一个局部 SWE 任务，远景用流向波纹，星球不运行 SWE。无实机 FPS 声明。 |

## 存档与兼容

新工程可解码 Perf3 的 v1 `.orbis` 存档，编码布局不变。为保持字节往返和原文明数值，**载入旧存档时保留原群系/肥力**，重建新的派生地貌/水体缓存；点击“手动重算排水、气候和地貌”才采用新分类与湖泊规则。重算前先另存备份。

新生成世界直接使用新规则。原 V4 球面 JSON 不覆盖、不自动迁移。导入高度图仍是生成新世界，不是完整存档导入。完整包应新目录打开，不要把整包覆盖到存在个人修改的工程中。

## 已知范围

气候是文明玩法用的合成季节模型，不是经过观测资料校准的 GCM；湿地、坡度阈值、输沙和河口范围都是明确的游戏尺度近似。局部 SWE 只做围绕静态基准水面的扰动，全球排水由高度和汇流负责，不将两者叠加成第二套世界水量。

本次没有完成完整潮汐、咸淡水密度分层、洪泛漫溢、全年动态径流、泥沙侵蚀/冲积造陆、真实三角洲分汊、HPWater 全部 HDRP 渲染特性。河口是有连通性约束的渐变扇形水色，不是已形成的新陆地。
