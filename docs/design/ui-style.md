# 界面设计规范：漆器朱像素风

本作所有界面（HUD、宽窗口、弹出提示）都照这份规范做。2026-11-28 定稿，参考图见 [ui-reference.png](ui-reference.png)。版式照模组「公司 · 产业格局」窗口的做法（一页一问、等大卡片网格、每卡结构相同、颜色只表含义、每卡一句结论）。
新界面先照本规范出参考稿，作者认可后再写代码；写代码只用 `EmpireCraft.UI` 的通用组件（见第 5 节），不另拼样式。

## 1. 原则

1. **立体，有像素感。** 框和按钮有厚度：上沿亮、下沿暗，外面一圈黑边。全部是硬边像素，不用柔和渐变，不用模糊阴影。
2. **一页只回答一个问题。** 页头左边写页名，右边用一句话把问题说破（如“产业格局 …… 各行业谁占多少，哪家在抬价”）。
3. **统一的格子。** 主指标卡等大、排一行；内容卡等大、排成网格（通常 2×2）。同一页的卡结构相同，看懂一张就会看全部。
4. **每张卡有固定结构，按阅读顺序排：** 标题 → 状态标签 → 图形（占比条、拉锯条、小图）→ 名单或明细 → 一句结论。读的顺序就是“什么状况 → 占多少 → 是谁 → 意味着什么”。
5. **替玩家下结论。** 每张卡底部用一句话（橙色）说出“所以呢”，例如“东瀛帝国握着本国钢铁两成”“未满停战年限，宣战会失信”。
6. **颜色只表达含义。** 底色和边框保持中性（黑漆底、暗色边带、金角）。颜色只用在：标签的类别、条上的分段（与图例小点一一对应）、不正常的数（红色只用于警报）。不用整张红卡、大片红色来强调。
7. **只有一层框。** 卡内的名单、明细用一块深色底，不再套带角的框。按钮和标签是例外。
8. **对齐严格。** 数字统一靠右成一列；标签框宽度一致；名字统一左对齐。
9. **字少。** 每格只放一个短词或一个数；解释集中在卡底的结论句，操作提示放在页面最底下一行。
10. **图标克制。** 图标只放在卡头、菜单和需要辨认的格子上，不在每一行、每个按钮上都加。
11. **做不了的要说明原因。** 不能点的按钮压暗并写明原因；有顾虑但仍能做的，挂橙色标签，按钮照样能点（玩家是神，不拦）。
12. **能在地图上选的，就用地图选。** 要挑国家、城、行政区时，窗口里放天下简图（第 5.6 节），点图即选。
13. **称谓和规则不写死。** 君主称号、官职、政体名、战争目标、继承法这类，一律通过核心的函数或语言表取（政体编辑器改了，界面跟着变）；界面代码只写界面自己的提示语。
14. **不要：** 表格行之间的点线分隔（标题后面的点线引导线可以用）、框里套框、默认粗体（像素字不加粗，强调靠颜色）、一行一个按钮的长列表、大小不一的卡片拼在一起。

## 3. 字体

- **Fusion Pixel 12px**（`Resources/EmpireCraft/Fonts/FusionPixel12.ttf`，OFL 授权，授权文件放在同一目录）。运行时建成位图字体，不用 SDF，以免发糊。
- 字号用 12（正文）、16（页头和窗口标题）、24（主指标大数字）。
- 不加粗，不用斜体。

## 4. 贴图（`Resources/EmpireCraft/Frames/Lacquer/`）

全部是 1:1 像素图，点采样、无 mipmap，九宫格拉伸。

| `window` | 8 | 窗口外框（黑边、亮暗两道斜边、内黑线） |

## 5. 通用组件（`EmpireCraft.UI.Arc`）

宽窗口一律用 `ArchiveWindow`：左栏 220px，放身份卡、页面菜单、步骤卡；右边是可滚动的主区。

### 5.1 基础
- `Arc.Card(title, icon, note, kind)`：卡片。kind 取 普通 / `gold` / `war` / `dim`。卡头写图标加标题，右边可挂小字或徽记。
- `Arc.Badge(text, tone)`：小徽记，tone 取 金 / r / g / o / c。
- `Arc.Button(text, icon, kind, click)`：按钮，kind 取 普通 / `gold` / `red` / `off`；`big` 是占满整卡宽度的大按钮。
- `Arc.Toast(icon, text)`：操作完成后显示在主区顶部的回执条。

### 5.2 引导
- `Arc.Steps(title, (state, text)...)`：步骤卡。state 取 已完成（绿勾）/ 当前（金色编号）/ 待做（灰）。凡是多步操作都要有。
- `Arc.StepMark(n)`：单个编号方块，放在操作卡里标出“先 1 后 2”。

### 5.3 选择
- `Arc.MenuItem(icon, text, count, active, click)`：左栏菜单项，选中时变成金色按下态。
- `Arc.IconGrid(items, selected, pick)`：带图标的格子阵（如宣战目标），选中格换 `tile_on`。
- `Arc.Chip(text, on, click)`：小切换签，用于切换图的着色方式、筛选。

### 5.4 数字
- `Arc.Tug(left, right, icon, leftColour, rightColour)`：两国拉锯条，中间放图标。
- `Arc.Meter(label, fraction, value, tone)`：属性条。
- `Arc.StatTile(icon, label, value)`：属性小格。
- `Arc.Kpis(...)`：页首几个主指标。

### 5.5 人与国
- `Arc.Flag(colour, text)`：国旗方块。`Arc.Medal(icon)`：带框头像。
- `Arc.IdCard(...)`：左栏身份卡。`Arc.Versus(a, b, state)`：两国对阵卡（两面国旗、中间关系牌、下面拉锯条）。
- `Arc.PersonCard(...)`：候选人卡（头像、名字、关系徽记、属性条、名望、按钮）。
- `Arc.Banner(icon, text, note, warn)`：分组横幅；`warn` 用红色横幅（如“外姓，立之即改朝”）。

### 5.6 天下简图（`Arc.MapPicker`）
窗口里的小地图，也是选择器。照模组外交窗口的关系图做：
- 底图按格子取样，硬边像素色块；国与国之间画黑线，本方描金边，选中的对象描白边。
- 调用方只提供两样东西：**每块怎么上色、标什么字**，以及**点了做什么**。外交、行政区、城市互动、诉求选目标都用同一个组件。
- 图上方是着色方式切换签（如 关系 / 可否开战 / 势力），图下方是图例和一行操作提示（点选、滚轮缩放、指着看详情）。
- 开图时自动对准相关的一片；滚轮缩放、按住拖动；指着哪块，图例行就换成它的名字和关系。

### 5.7 内容卡（`Arc.InfoCard`）
每张内容卡都用同一个骨架：标题加状态标签（卡头右侧）、一个图形区、一块深色底的明细（可省）、一句结论（橙色），需要时卡底放一个按钮。
- `Arc.ShareBar(segments)`：分段占比条，每段一种颜色，下面跟图例小点。
- `Arc.ListBlock(rows)`：深色底明细，每行是 名字 · 类别标签 · 靠右的数字。
- `Arc.Verdict(text, tone)`：卡底的结论句。
- 做不了的操作：按钮换 `btn_off`，结论句写原因。

## 6. 版式

```
┌ 标题栏：返回 · 图标+窗口名 · 关闭 ─────────────────────────┐
│ 左栏 220px        │ 页头：页名 ……………………… 一句话说明这页的问题 │
│ · 身份卡          │ [主指标] [主指标] [主指标] [主指标]   ← 等大一排 │
│ · 页面菜单        │ ┌ 内容卡 ┐ ┌ 内容卡 ┐                         │
│ · 步骤卡          │ │标题 标签│ │标题 标签│  ← 等大网格，结构相同   │
│                   │ │图形     │ │图形     │                         │
│                   │ │明细     │ │明细     │                         │
│                   │ │结论句   │ │结论句   │                         │
│                   │ └────────┘ └────────┘                         │
│                   │ · 底部一行：操作提示                          │
└───────────────────┴───────────────────────────────────────────────┘
```

- 刚做完操作时，页头下面先显示一条回执。
- 主操作放在它所在的卡里：卡底一个按钮。宣战这类危险操作用红色按钮，全页只有这一处红色按钮。
- 暂不开放的操作收在页底的锁定小签里。
- 间距只用 4 / 8 / 12：卡与卡之间 8，卡内 4。
