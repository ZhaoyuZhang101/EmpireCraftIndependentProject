## 1. 排雷核心：为什么原版 ExoPlaSim 会出现“东南亚沙漠”，以及 ORBIS 四重防线

### 1.1 原版 ExoPlaSim 病根诊断
1. **`T21 (64×32)` 粗谱截断 + 吉布斯（Gibbs）伪下沉环**：单格宽约 `5.6° (~600 km)`，中南半岛、马来半岛与南洋群岛在球谐谱展开中被抹成低矮半海半陆残影；喜马拉雅陡坡谱截断在孟加拉湾—中南半岛激发非物理的吉布斯下沉抑制区。
2. **`50 m` 静止平板海洋（`qflux = 0`）缺失印太暖池**：无风驱西边界流堆积与印尼贯穿流，南海与孟加拉湾海温偏低，初夏季风水汽通量不足。
3. **郭氏（Kuo）网格尺度对流漏掉半岛/群岛海陆风日变化湿辐合**：真实东南亚与海洋性大陆超过一半降水来自狭长海岸午后海风辐合深对流，粗网格平均相对湿度低于阈值即整格断雨。
4. **单桶浅层土壤干死正反馈**：一旦春季少雨，单层土壤迅速干涸 → 潜热蒸发骤降、感热与干土反照率飙升 → 抬升凝结高度暴涨，全年锁死在 `BWh / BSh` 荒漠态。

### 1.2 ORBIS 四重物理防线（零坐标硬编码，纯物理几何判据）
1. **保留高分辨率海陆场与动态风驱洋流/暖池**（[FlatOceanCirculation.cs](file:///d:/ORBIS_TerrainPerf3_5_Markley/Assets/ORBIS/Runtime/FlatWorld/Core/FlatOceanCirculation.cs)）：绝不用粗谱截断覆盖精细海岸线，完整保留西太平洋—东印度洋暖池海温正异常。
2. **暖海环绕半岛/群岛海陆风湿辐合护栏（`MaritimeSeaBreezeGuard`）**：
   - 在 `|lat| < 26°` 采样四象限近岸海域（`180–650 km`）与大区域开阔大洋占比（`1,200 km` 半径 `>= 0.40`，自动排除红海—波斯湾夹持的阿拉伯半岛内陆副高荒漠及冷涌升西海岸）；
   - 当暖水环绕狭长半岛或群岛（如中南半岛、马来半岛、苏门答腊、爪哇、婆罗洲、菲律宾、中美洲）且海温 `> 24 °C` 时，显式激发日变化海风低层水汽辐合与对流触发增益，物理上阻断干季锁死。
3. **浅层表皮（`35 mm`）+ 深层根区（`145 mm`）双层水库缓冲**：表皮控制瞬时裸土蒸发与湿土变暗反照率，深层根区支撑季风林干季蒸腾回馈，防止单桶瞬时晒干。
4. **硬性自动化回归红线（`ExoPlaSimSupplementRegression`）**：
   - 地球预设（`256` 至 `2048`）上，**中南半岛（`97–109°E, 8–22°N`）与南洋群岛（`95–130°E, 10°S–10°N`）热/冷沙漠气候（`BWh/BWk`）及沙漠地表（`Biome.Desert`）占比必须严格等于 `0.0%`**，且中南半岛与菲律宾年均雨量较移植前进一步向 CRU 观测真值靠拢。

## 2. 五大移植模块与物理方程

### 2.1 对流性降水（`Convective`）vs 大尺度层状降水（`Stratiform`）拆分 + 逆温盖 `CIN`
参考 ExoPlaSim `rainmod.f90`（`kuo` 深对流 + `lsp` 大尺度凝结）：
- **对流有效位能 `CAPE` 与对流抑制 `CIN`**：
  $$\text{CAPE} = \max\!\left(0,\; c_{\text{cape}} \cdot (T_s - 15^\circ\text{C}) \cdot \text{RH}_{\text{BL}}^{1.35} \cdot (1 + 0.45\,G_{\text{breeze}})\right) \cdot (1 - 0.72\,S_{\text{STHZ}})$$
  $$\chi_{\text{lid}} = \text{clamp}\!\left(0.55\,S_{\text{STHZ}} + 0.45\,D_{\text{dry}} - 0.50\,G_{\text{breeze}},\, 0,\, 1\right)$$
- **干区抑雨与湿区聚雨**：
  - 副高下沉与深内陆荒漠区（高 $\chi_{\text{lid}}$、低湿）：深对流关闭，层状云临界饱和阈值提高至 `0.93`，配合云下干层雨滴再蒸发（Virga），消除撒哈拉/阿拉伯/内陆盆地虚高毛毛雨（攻克 `BWh → BSh` 头号错分），同时保持逐格水汽质量严格守恒（再蒸发水汽全部留存气柱）。
  - 印太暖池、孟加拉湾、西高止山、亚马孙与东南亚半岛（高 `CAPE` + 海风辐合护栏 $G_{\text{breeze}}$）：深对流高效集中释雨，提升 `> 1,500 mm` 湿润带雨峰；干季外缘大陆草原抑制残余虚高对流毛毛雨，改善 `Aw/Am → Af` 混淆。
  - 高纬冷季斜压锋面（`|lat| >= 50°`）：保留层状固态降雪效率，减少亚寒带 `Dfc → Dwc` 误判。

### 2.2 四分量地表/TOA 辐射能量收支、湿土反照率、五层土壤热扩散与昼夜温差 `DTR`
参考 ExoPlaSim `radmod.f90` 与 QoL 陆面方案：
- **湿土变暗地表反照率（`Wet-soil Albedo`）**：
  $$\alpha_{\text{soil}} = \alpha_{\text{dry}} - \Delta\alpha_{\text{wet}} \cdot w_{\text{skin}}, \qquad \alpha_{\text{surf}} = (1 - f_{\text{snow}})\big[(1 - f_{\text{veg}})\alpha_{\text{soil}} + f_{\text{veg}}\alpha_{\text{veg}}\big] + f_{\text{snow}}\alpha_{\text{snow}}$$
- **大气温室光学厚度与出射长波辐射 `OLR`**：
  $$\tau_{\text{LW}} = \tau_0 \left(\frac{p}{p_\oplus}\right)^{0.65} + a_{\text{CO}_2}\ln\!\left(\frac{\text{CO}_2}{280}\right) + a_{\text{wv}}\sqrt{W_{\text{vap}}} + a_{\text{cld}} f_{\text{cld}}$$
  $$\text{OLR} = \frac{\sigma T_s^4}{1 + 0.75\,\tau_{\text{LW}}} (1 - 0.36\,f_{\text{high\_cld}})$$
- **感热（`SH`）、潜热（`LH`）与昼夜温差 `DTR`**：
  - 按土壤表皮水分与风速计算蒸发潜热 `LH` 与波文比（Bowen Ratio），干沙漠净辐射主要转化为感热与夜间长波辐射冷却，`DTR` 达 `15–21 °C`；湿润雨林/季风海岸潜热主导且高湿多云阻挡夜间冷却，`DTR` 为 `5–9 °C`；开阔大洋热容巨大，`DTR` 为 `1.2–2.8 °C`。
- **五层土壤热扩散（`0.4, 0.8, 1.6, 3.2, 6.4 m`）与高纬积雪消融后回暖**：
  - 复刻 ExoPlaSim 五层指数递增土层热传导，捕捉高纬（`|lat| >= 54°`）初夏积雪消融后湿暗表土与针叶林冠层在极昼长日照下的快速浅层升温，直接修正高纬最暖月 `10 °C` 森林—苔原边界的 `-0.77 °C` 冷偏差。

### 2.3 风暴气候学（`Storm Climatology`：`CAPE` / `MPI` / 熵亏 / 垂直风切变 / `GPI`）
参考 `web-exoplasim-qol` `Storms` 面板（Emanuel–Bister 潜在强度与 Emanuel–Nolan 生成指数）：
- **最大潜在强度 `MPI`（`m/s`）**：由海表温度 $T_s$、对流层顶出流温度 $T_o$ 与海气饱和湿静力能差决定。
- **垂直风切变 `ShearMs`（`m/s`）**：由近地风矢量与高空 Rossby/副热带急流 + 热成风切变合成。
- **气旋生成指数 `GPI`**：
  $$\text{GPI} = |\eta|^{1.5} \cdot \left(\frac{\text{RH}_{\text{mid}}}{0.70}\right)^3 \cdot \left(\frac{V_{\text{MPI}}}{70}\right)^3 \cdot (1 + 0.1\,V_{\text{shear}})^{-2}$$
  同时驱动实时气旋模拟 [FlatCycloneWeather.cs](file:///d:/ORBIS_TerrainPerf3_5_Markley/Assets/ORBIS/Runtime/FlatWorld/Core/FlatCycloneWeather.cs) 与西北太平洋（菲律宾/华南/台湾）、孟加拉湾、加勒比海夏秋台风有组织水汽输送。

### 3.3 辐射收支、风暴气候学与行星预设物理检验
- **全球辐射能量收支（现代地球 `256`）**：大气顶净短波吸收 **`236.3 W/m²`**、出射长波 **`OLR = 240.7 W/m²`**（与 NASA CERES 观测 `~239 W/m²` 高度吻合）、全球平均地表反照率 **`0.172`**。
