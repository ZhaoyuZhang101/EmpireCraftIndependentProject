# ORBIS UI 设计定稿：方案 A「侧轨神力栏」（Edge-Rail God-Bar）

关联交互原型稿：
- `Preview/OrbisUI_Round2_Proposals.html`（工程内置独立浏览器预览版，方案 A）

本方案已确认作为后续 UI 重构基准，暂缓施工，待气候系统升级完成后统一落地至 `FlatWorld.uxml` / `FlatWorld.uss` / `FlatWorldApp.cs` 及 `FlatScrollNavigator.cs`。

## 一、核心交互结构

摒弃现有固定占屏的顶栏（`90px`）、左侧常驻栏（`280px`）与底栏（`64px`），将摄像机视口扩展为 **100% 全屏铺满**，所有控件采用 WorldBox 式的像素深色木框悬浮面板：

1. **左上：时间与人口微面板**
   - 包含 `[⏸/▶ 暂停]`、`[1× / 4× / 12× / 20× 倍速]`、`当前年月` 及 `总人口 / 国家数`（移动端竖屏精简为单行 `1年1月`）。
2. **右上：三尺度切换胶囊**
   - 统一收敛原先散落在 3 处的视野按钮为：`[🌐 星球]` · `[🗺️ 总览 (M)]` · `[🔍 地表 (F)]`。
   - 手机竖屏在此处附加 `[🧭 小地图开关]` 按钮，点击按需展开 Hammer 投影小地图。
3. **左侧垂直神力侧轨（PC & 手机横屏）**
   - 宽度约 `56px`，垂直居中（手机横屏因纵向高度较矮，挂接于左上时钟下方），常驻 6 个一级分类图标按钮：
     - `观察`（查看、自然/疆域/温度/降水/高程图层、网格、气候图集）
     - `塑造`（隆起、沉降、定高笔刷、平滑、重算水文、找河口）
     - `文明`（播种、建国、扩张、列国排行，以及后续《帝国盒子》战争/宗族/制度入口）
     - `营建`（农田、道路、桥梁、海上航线）
     - `天象`（云层云影、昼夜晨昏、画质档位）
     - `世界`（新世界生成、保存、读取、纯净截图）
   - **弹出与收起规则**：点击任一分类，紧贴侧轨右侧弹出 3 列图标格面板；再次点击同一分类、`✕` 或点击地图空白处自动收起弹出面板。
4. **底部中央：手持工具与笔刷上下文条**
   - 未选工具时完全隐藏，底部视野零遮挡。
   - 选中工具后悬浮显示：`[笔刷范围 1×1 / 3×3 / 4×4区 / 9×9]`、`[定高步进 − 档位 +]`、`[↩ 撤销]`，以及下方 `[手持：工具名 | ✕ 放下]` 胶囊（替代鼠标右键取消）。
5. **跟随式地块信息卡（PC & 横屏）**
   - 仅在无工具「查看」状态点击地块时弹出，贴靠在选中坐标侧旁（靠屏幕右半侧时自动翻转至选点左侧；左侧弹出格展开时优先避让至选点右侧）。
   - 展示归属政权、海拔档位、气温、降水、人口、设施、地表群系，以及 `[聚焦 F]`、`[图集]` 快捷入口。

## 二、移动端专项适配（竖屏单手 + 横屏双拇指）

1. **手机竖屏（Portrait）变形规则**
   - 左侧竖轨自动下沉转化为 **底部 6 格分类主栏**（拇指热区）；
   - 点击分类向上弹出 **4 列图标抽屉**；
   - **选中工具自动折叠（WorldBox 手游核心体验）**：当玩家在 4 列抽屉中点选任一地形/建造工具后，抽屉自动浓缩为 **单行横向滑动条**，立刻把中央地图露出来供手指涂抹；
   - 未展开分类且查看地块时，底部主栏上方浮现 **单行摘要条（Peek Sheet）**，点 `[详情]` 展开完整地块属性卡。
2. **手机横屏（Landscape）变形规则**
   - 保留左侧细竖轨供左手拇指点按分类，右手拇指负责地图平移与施放；右下保留紧凑版小地图。
3. **防误触与多指手势规范**
   - 笔刷上下文条在移动端额外显示 **`[拖图 / 涂抹锁]`** 切换键：
     - `拖图`（默认安全态）：单指滑动平移视野，单指轻点施放一次；
     - `涂抹锁`：单指滑动连续刷地形/铺路，双指滑动平移视野；
   - 双指捏合（Pinch）直接接入 `FlatScrollNavigator.Wheel(delta, midpoint, day)`，连续跨越太空星球、展开过渡与局部正视地表；
   - 全端严格遵守 `Screen.safeArea`，避开顶部灵动岛/挖孔与底部 Home 横条。
